# 🎮 Number Guessing Game (Python)

একটি সহজ কিন্তু মজাদার পাইথন গেম যেখানে কম্পিউটার একটি সংখ্যা নির্ধারণ করে এবং আপনাকে সেটি অনুমান করতে হয়। এটি মূলত আমার পাইথন শেখার এবং লজিক বিল্ডিং প্র্যাকটিসের একটি অংশ।

## 🚀 বৈশিষ্ট্য (Features)
* **Simple Logic:** পাইথন ব্যবহার করে তৈরি সহজবোধ্য গেমপ্লে।
* **User Interaction:** ব্যবহারকারীর ইনপুটের ভিত্তিতে প্রতিক্রিয়া জানায়।


## 🛠️ প্রযুক্তি (Technologies Used)
* **Language:** Python
* **Library:** `random` (সংখ্যা জেনারেট করার জন্য)
